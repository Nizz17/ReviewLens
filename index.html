    How this was built

    Raw reviews went through a big data pipeline before reaching this page.

    HDFS

    StoreRaw review file kept in Hadoop’s distributed file system (Labs 1-4).

    MR

    MapReduceAverage, lowest and highest rating per product, plus word counts with stop words removed (Labs 6-11).

    Pig

    Pig and HiveSort, group, join and SQL-style queries over the results (Labs 12-13).

    Spark

    SparkSame rating job re-run to compare speed with MapReduce (Lab 14).

    DB

    MongoDB and CompassResults stored as collections, then filtered and explored in Compass.

    Web

    This pageA friendly view of the exported collections.
